# Security

Run the service on loopback with a dedicated DSM account on a trusted NAS. Local users can reach the listeners. Keep the upstream camera on a trusted network. HTTP SOAP and RTSP/TCP can expose protocol details to observers on the camera network.

Report suspected vulnerabilities to the repository owner through an available private contact channel. Include affected versions and a synthetic, redacted example. Keep credentials, full captures, private network details and recordings out of public issues.
